# Music

Music browses and plays local audio. Import a file, a `file:` URL or a folder; folder imports scan recursively without following nested symlinks. A directly selected symlink resolves to its target; directly selected audio files do not require a particular extension. The library reads title, artist, album, year, track number and duration from actual media tags through ffprobe. A missing title falls back to the filename; albums without tags group by folder. Artwork comes from a local `cover.png` / `folder.png`, or an embedded picture converted to PNG by ffmpeg.

Albums, Artists, Songs and Recently added show the imported library. Search matches title, artist and album. Album playback, shuffle and Add to queue use the visible tracks. The queue supports Enter/double-click playback, removing a selected entry and clearing upcoming entries. Previous, Play/Pause, Next, Stop, seek and volume control the existing mpv `PlaybackSession`; only a real EOF event advances the queue. File associations open paused. Stop retains the queue and Play reopens the current track.

The library is stored in `$XDG_DATA_HOME/moire/music/library.json` (or `~/.local/share/moire/music/library.json`). Writes use an exclusive lock, optimistic revision check and atomic replacement. Malformed storage is preserved. Removing a library entry leaves the audio file in place. Imports are cancellable and limited to 5000 tracks and 16 folder levels. Reload resolves external library changes before further edits.

The shared `AdaptivePanes` preserves mounted pane state through resize, owns divider input and collapses panes into accessible views when space is limited. The playback bar remains below those views. `WindowFrame` provides the application identity and actual window move/minimize/maximize/close actions. Navigation and track collections retain keyboard arrow/Home/End/Enter behavior.

The ordered queue is saved beside the library in `queue.json`, including distinct repeated entries, the current entry and last observed playback position. Reopening restores it stopped with an explicit Resume action. Resume opens paused and seeks before playback starts. Missing media remains listed and reports an error when opened; Remove and Next remain available. Active playback checkpoints every five seconds, while pause, stop, queue edits and close flush the latest observation. Failed saves preserve the draft and block automatic writes. Retry retains the loaded revision; Reload saved queue confirms before discarding the draft and stopping playback. The shared atomic store preserves malformed bytes and conflicting external edits. An unsaved draft remains in this window, and closing it does not make that draft durable. In a RAM-only VM boot, queue and library state disappear on poweroff.

## Current limits

The approved Music v0 reference guides pane structure, album artwork density and transport hierarchy. Its serif album heading is represented with the bundled sans font; Moire has no bundled serif face. Sample captures use real generated audio tags and Moire's botanical asset, rather than claiming the reference album exists in a user's library. No streaming, device chooser, favorites, persistent playlists, recommendations or repeat mode is implemented. The queue survives app relaunch in the same writable home, but named playlists are not implemented. The path entry is the current local import workflow; it is not a native file picker. Sidecar artwork currently supports PNG; embedded JPEG pictures are converted to PNG. Large libraries use fixed-row virtualization, not an album grid. Album grouping currently uses performer plus album/folder tags; grouping compilations by a dedicated album-artist tag remains a follow-up.

Metadata options follow the [ffprobe documentation](https://ffmpeg.org/ffprobe.html), and transport/EOF semantics follow the [mpv manual](https://mpv.io/manual/stable/).
