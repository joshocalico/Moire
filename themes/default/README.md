# Default Moire theme

`theme.json` is the source of truth for:

- **tokens** — colors + chrome metrics (shell SSD/panel, compositor)
- **wallpaper** — `solid` or vertical `gradient` (painted by the compositor)

Override path with `MOIRE_THEME=/path/to/theme.json`.

GTK CSD overrides live in `themes/Moire/` and should stay visually aligned with these tokens.
